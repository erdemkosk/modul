# Rocket audio

`launch.wav` is mixed by hand (a Python one-off) from two files of the Mud Run project (`../car`):
`assets/audio/combat/smoke_hiss_loop.wav` (the project's own synthesized hiss) sped up and faded as the motor
burns out, and `assets/audio/war/artillery_launch_far_01.wav` (Freesound FS-486027, CC0 1.0) for the thump.
Released under CC0 like its sources.
