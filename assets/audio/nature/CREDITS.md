# Nature ambience credits

Taken from the Mud Run project (`../car/assets/audio/nature`, built there by `tools/audio/build_world_audio.sh`
as seamless crossfaded loops). Every source recording is **CC0 1.0 (public domain)**; no attribution is
required. The author is credited anyway.

| File | Use | Source | Author | Licence |

| `stream_gentle_loop.ogg` | Gentle stream, 60 s | Brooklet (BigSoundBank 0864) | Joseph Sardin, BigSoundBank | CC0 |
| `wind_cold_pass_loop.ogg` | Cold wind: strong gusts with a low whistle, 37 s | Strong Wind #4 (BSB 0154) + Whistling of the Wind #2 (BSB 0155, low-passed) | Joseph Sardin, BigSoundBank | CC0 |

The crickets at night are synthesised in the game (`scripts/ambience.gd`).
